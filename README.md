# 말로 부르는 버스 (가칭)

청년 공공AX 서포터즈 · 공드리팀

수요응답형 교통(DRT, 부르면 오는 버스) 예약 상담원을 돕는 AI입니다. 어르신은 지금처럼 사람과 통화하고, AI는 상담원 옆에서 통화를 받아 적고 예약 양식을 채우고 정류소 후보를 추천합니다. 상담원이 없는 시간에만 AI가 요청을 받아 두고, 모든 예약은 사람이 확정합니다.

서비스 설명, 근거, 개발 계획은 [서비스소개.md](서비스소개.md)에 있습니다.

## 지금 들어 있는 것

| 파일 | 내용 | 상태 |
|---|---|---|
| `agent.html` | **상담원 통화 보조 화면** (핵심): 통화 내용 → 예약 양식 자동 채움, 정류소 후보와 "확인 필요" 표시, 확정, 접수 시간 측정, 별칭 저장 | 기초 동작 |
| `index.html` | 상담원이 없을 때의 **AI 접수** 화면: 되묻기, 되읽기 확인, 확인 필요 정도별 대기열 | 동작함 |
| `engine.js` | 두 화면이 함께 쓰는 엔진: 정류소 목록, 별칭 사전, 예약 정보 추출 (규칙 기반) | 동작함 |
| `서비스소개.md` | 서비스 설명과 2주 개발 계획 | 최신 |

## 실행 방법

설치할 것은 없습니다. 크롬에서 파일을 열면 됩니다. API 키도 필요 없습니다(규칙 기반으로 동작).

**상담원 통화 보조 (`agent.html`)**
- "▶ 같은 이름 회관" 같은 대본 버튼을 누르면 통화가 한 줄씩 들어오고, 오른쪽 양식이 채워집니다.
- "확인 필요"가 붙은 칸만 고르고 **확정**을 누릅니다. 아래에 접수 시간이 기록됩니다.
- "▶ 처음 듣는 지명"에서 출발을 계촌리 경로당으로 골라 확정하면 "윗말 정자나무"가 별칭으로 저장되고, 다시 재생하면 바로 추천됩니다.
- 통화 내용을 직접 입력하거나, 크롬에서는 마이크로 받아 적을 수도 있습니다.

**AI 접수 (`index.html`)**
- 어르신이 하는 말을 입력하거나 예시 버튼을 누르면 AI가 빠진 정보를 되묻고, 되읽어 확인한 뒤 대기열로 넘깁니다.
- 대기열은 빨강(상담원 직접 통화), 노랑(AI가 추정한 부분 확인), 초록(확인 후 확정)으로 나뉩니다.

## 범위와 한계

- 실제 콜센터 전화망·ARS와 연결하지 않습니다. 통화는 대본·녹음·텍스트 입력으로 재현합니다.
- 정류소는 시연용 예시이며 실제와 다를 수 있습니다.
- 배차 시스템 연동, 노쇼 처리, 도착 알림 전화는 포함하지 않습니다.
