# 말로 부르는 버스 (가칭)

청년 공공AX 서포터즈 · 공드리팀

수요응답형 교통(DRT, 부르면 오는 버스)을 앱 대신 **전화·문자로 평소 말투 그대로** 예약하면, AI가 예약 정보를 정리하고 상담원은 확인이 필요한 건만 승인하는 서비스의 시제품입니다.

## 왜 필요한가

- 인구 감소 지역의 노선버스가 DRT로 바뀌고 있지만, 앱이나 콜센터로 직접 호출해야 해 고령자 등의 이용 장벽이 있습니다 (국토교통부 「수요응답형교통(DRT) 도입·운영 가이드라인」, 2025.12, p2).
- 앱으로만 부를 수 있는 DRT도 있고, 전화로 부르려면 정류장 번호를 알아야 하는 지역도 있습니다.
- 콜센터를 두려면 상담원 채용과 지역 지명 교육이 필요합니다 (같은 가이드라인 p139, p183).

## 실행 방법

`index.html`을 크롬에서 열면 됩니다. 설치할 것은 없습니다.

- 왼쪽 **통화 화면**에 어르신이 하는 말을 입력하거나 예시 버튼을 누릅니다.
- AI가 빠진 정보를 되묻고, 예약 내용을 읽어 확인받은 뒤 오른쪽 **상담원 화면**으로 넘깁니다.
- 상담원 화면은 확신도별로 나뉩니다: 빨강(상담원 직접 통화), 노랑(AI가 추정한 부분 확인), 초록(그대로 승인 가능).

파일을 직접 열면 규칙 기반 **데모 모드**로 동작합니다. Claude 페이지로 게시하면 Claude가 예약 내용을 이해합니다.

## 현재 범위와 한계

- 글자 입력 기반입니다. 음성 입력(크롬 내장 음성 인식)은 개발 단계에서 추가합니다.
- 정류소 8곳은 시연용 예시이며 실제와 다를 수 있습니다.
- 실제 전화망, 배차 시스템 연동, 노쇼 처리, 도착 알림 전화는 포함하지 않습니다.
