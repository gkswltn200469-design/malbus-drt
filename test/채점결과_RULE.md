# 채점 결과 (RULE 모드)

- 대상: `test/대본_정답지.csv` 대본 20개를 `POST /extract`에 넣은 결과 (규칙 모드, 배운 별칭 없음)
- 다시 만들기: `cd backend && ./gradlew grade` (이 파일을 덮어씀)
- 판정 기준
  - 목적·날짜·시간·인원: `value`가 정답과 같으면 O. 정답 빈칸은 `null`이어야 O
  - 출발·도착: 정답이 ID 하나면 `value`가 같아야 O. `S01|S12`처럼 여럿이면 `value`가 비고 후보가 정확히 그 정류장들이어야 O. 정답이 빈칸이면 `value`도 비고 후보도 없어야 O
  - 확인필요: 출발·도착·날짜·시간·인원 중 `needsCheck = true`인 칸 묶음이 정답지 `확인필요`와 똑같아야 O

## 참고

- 인원을 말하지 않은 예약은 1명(`said = null`, `source = RULE`)으로 채움. 변경·취소·문의는 빈칸 (11/11 결정)
- 인원 결과가 빈칸인데 정답지에는 값이 있는 경우: 0건
- 확인필요가 인원 칸 하나 때문에만 틀린 경우: 0건
- 변경·취소·문의 대본에서 확인필요가 틀린 경우: 4건. 정답지는 이 대본들의 확인필요를 비워 두고, BE는 빈칸도 `needsCheck = true`로 둠 (`docs/api.md` Field 정의)
