# 채점 결과 (RULE 모드)

- 대상: `test/대본_정답지.csv` 대본 20개를 `POST /extract`에 넣은 결과 (규칙 모드, 배운 별칭 없음)
- 다시 만들기: `cd backend && ./gradlew grade` (이 파일을 덮어씀)
- 채점 칸: 출발, 도착, 날짜, 시간, 확인필요. 목적('이동수단 예약' 고정)과 인원(화면 제외)은 채점하지 않음
- 판정 기준
  - 날짜·시간: `value`가 정답과 같으면 O. 정답 빈칸은 `null`이어야 O
  - 출발·도착: 정답이 ID 하나면 `value`가 같아야 O. `S01|S12`처럼 여럿이면 `value`가 비고 후보가 정확히 그 정류장들이어야 O. 정답이 빈칸이면 `value`도 비고 후보도 없어야 O
  - 확인필요: 출발·도착·날짜·시간 중 `needsCheck = true`인 칸 묶음이 정답지 `확인필요`와 똑같아야 O
